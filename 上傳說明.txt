資金規劃系統 V4 品牌整合版

GitHub Pages 上傳方式：
1. 將此資料夾內所有檔案一起上傳到 money-planner 儲存庫根目錄。
2. index.html 必須位於根目錄。
3. 等待 GitHub Pages 重新部署後，重新整理網站。
4. 手機若仍顯示舊圖示，先移除舊的主畫面捷徑，再重新加入主畫面。
