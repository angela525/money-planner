# Dream Tree V7.1 — 歡迎引導修正版

修正內容：
- 每個帳號第一次進入 V7.1 時，歡迎引導必定出現一次。
- 不再因舊版 profile 文件已存在而直接略過。
- 完成或略過後，才會記錄本機已看過。
- 帳號選單新增「重新開啟新手引導」。
- 登出時會自動關閉引導視窗。
- 保留 Google、Email 登入與 Firestore 同步。

部署後測試：
1. 覆蓋全部檔案並 Commit / Push。
2. 等 GitHub Pages 完成部署。
3. 重新整理網站。
4. 若帳號已登入，可先登出再登入。
5. 也可從右上角帳號選單點「重新開啟新手引導」。
